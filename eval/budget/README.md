The local evaluator keeps its authoritative, hash-chained `ledger.jsonl` here and rebuilds `state.json` from it. Every live dispatch reserves first; unreported costs and interrupted attempts retain the full reservation. Maximum USD 0.10 per attempt and USD 2 cumulative across all runs. No automatic reset or stale-lock removal exists. A surviving `ledger.lock`, corrupt/truncated journal or price/config failure refuses dispatch and requires an operator audit. Do not remove budget files to retry an evaluation. The held-out guard is also stored here, created exclusively before any held-out work; interrupted/incomplete held-out attempts consume the one-run grant. Local files are concurrency-safe on one filesystem, not a distributed OneDrive lock; run on one machine only. Back up the ledger before relocation.
